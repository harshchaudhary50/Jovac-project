# NoteX 📝

> AI-powered exam notes generator that transforms complex study material into concise, exam-ready notes.

## 🚀 Overview

NoteX is a MERN-stack based AI-powered notes generation platform designed to help students study smarter and faster.

It converts lengthy textbooks, lecture content, PDFs, and syllabus topics into high-yield notes, quick revision sheets, flowcharts, and downloadable PDFs.

## ✨ Features

- 🤖 AI-powered notes generation
- 📚 Generate notes from study material
- ⚡ Quick revision / cheat sheets
- 🧠 Simplified explanations of complex topics
- 📊 Auto-generated flowcharts
- 📄 Download notes as PDF
- 🎯 Syllabus-focused content
- 💳 Credit-based usage system
- 🔐 User authentication
- 📱 Responsive and modern UI
